FAQ

Questions fréquentes

Quelques réponses pour préparer ton apprentissage.

Puis-je commencer sans expérience ?

Oui, le parcours proposé peut commencer par les bases. Indique ton niveau dans le formulaire pour discuter de l'accompagnement adapté.

Puis-je apprendre avec un téléphone ?

Oui, il est possible d'apprendre les bases du développement web avec un téléphone Android et un éditeur de code adapté. Certains projets seront toutefois plus faciles sur ordinateur.

Quels projets pourrai-je réaliser ?

Selon ton niveau et le programme, tu pourras travailler sur des pages web, un portfolio, une application de gestion ou d'autres projets pratiques.

Comment connaître les horaires et les tarifs ?

Contacte CODE CAM sur WhatsApp pour demander les informations disponibles sur les horaires, les modalités et les éventuels frais.

Mon inscription est-elle confirmée après le formulaire ?

Non. Le formulaire prépare un message WhatsApp. Tu dois l'envoyer puis échanger avec l'équipe pour connaître les prochaines étapes.
